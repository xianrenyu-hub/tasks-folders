Tasks Folders · 隐私政策 / Privacy Policy

Last updated: 2026-10-10 · 更新日期：2026-10-10

一句话总结 / TL;DR

本扩展不收集、不上传、不追踪任何个人数据。你的文件夹结构只保存在本地浏览器中。

This extension does not collect, upload, or track any personal data. Your folder structure is stored only in your local browser.

1. 我们收集什么 / What We Collect

不收集任何东西。我们不知道你的身份、浏览历史或任务内容。

We collect nothing. We do not know your identity, browsing history, or task contents.

2. 数据存储 / Data Storage

  • 文件夹 / 归档 / 模板结构：仅保存在浏览器本地存储（chrome.storage.local）；
  • 导出 / 导入：你手动导出 JSON 时，文件由你自己保存和管理；
  • 卸载扩展：本地数据一并清除（建议先导出备份）。

3. Google Tasks API（可选功能）/ Google Tasks API (Optional)

仅当你主动开启「从模板一键生成清单」时，本扩展会通过 Google 官方授权（OAuth）访问你的 Google Tasks 数据，用于创建清单和任务。授权令牌由 Chrome 浏览器安全保管，本扩展无法读取你的密码。

Only when you opt in to "create a list from a template" does the extension access your Google Tasks data via official Google OAuth, to create lists and tasks. Tokens are managed securely by Chrome; we never see your password.

4. 第三方 / Third Parties

  • Google（Google Tasks API）——仅在你使用上述可选功能时交互；
  • 无广告、无分析、无统计 SDK。

5. 安全 / Security

扩展权限最小化：仅申请 storage 与 identity 两个权限，无后台网络请求、无内容读取范围外的访问。

6. 联系我们 / Contact

问题或反馈：请在 GitHub 仓库提交 Issue（github.com/xianrenyu-hub/tasks-folders）。

本政策仅适用于 "Tasks Folders" Chrome 扩展。
